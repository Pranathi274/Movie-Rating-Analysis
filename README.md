# Movie Rating Analysis

## Project Overview

This project analyzes IMDb movie data to understand movie ratings, genres, release years, runtime, votes, revenue, and Metascores.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

IMDb Movie Dataset

## Analysis Performed

- Movie rating analysis
- Genre analysis
- Year-wise movie analysis
- Runtime analysis
- Votes analysis
- Revenue analysis
- Metascore analysis
- Correlation analysis

## Key Questions

1. What is the average movie rating?
2. Which movies have the highest ratings?
3. Which genres are most common?
4. Which genres have the highest average ratings?
5. How does the number of movies vary by year?
6. Is there a relationship between runtime and rating?
7. Which movies received the most votes?
8. Which movies generated the highest revenue?
9. Is there a relationship between IMDb rating and Metascore?

## Conclusion

The project provides insights into movie ratings and their relationship with different movie characteristics using exploratory data analysis and visualization.
